# Competitor notes — what to steal, what not to copy

Visited 2026-08-21. Rewrite in Enovak’s voice. Do not lift sentences, founder names, project counts, or brand-representation claims.

| Site | URL |
| --- | --- |
| Precisa Techno Trade | https://precisabd.com/ |
| DREKS Associates | https://dreksassociates.com/ |
| Saka International | https://www.sakaint.com/ |

All three are BD pharma/industrial equipment + turnkey firms. Precisa and Saka are **one long landing page**; products/divisions are the only real inner pages. That is Enovak’s IA.

---

## 1. Precisa Techno Trade — closest analog

**IA:** Single scrolling homepage. Nav is in-page. No separate About/Services/Contact routes. Clients as a logo carousel at the bottom.

**Positioning:** “Engineering firm supplying industrial equipment to Bangladeshi pharmaceutical companies, technology from manufacturers worldwide.”

**About pattern:** founded-by + year → what they supply/install/commission/validate → source countries → bullet list of services → engineer headcount + on-call servicing → MD name/title.

**Services they list on the landing itself (not separate pages):**
- New Plant Design and Engineering
- Process Consulting
- Clean Room and HVAC Systems
- Pharma Water Systems
- Production and Process Equipment
- Packaging Equipment
- Laboratory Equipment
- Testing, Commissioning and Validation

**HVAC block is their hero service:** design → load calc → install → commission → validate → after-sales + spare parts. They also do PW / WFI / pure steam turnkey.

**Showcase = process-line achievements, not logos.** That’s the model for Enovak’s Client Showcase:

- Solid oral (dispensing → sieving → blending → granulation → tabletting → coating → packing)
- Semi-solid / suppository
- Liquid filling
- Soft gel
- Hormone / OEB
- Insulin (vial, cartridge, PFS)
- Sterile / eye / nasal
- Lyophilisation
- DPI / MDPI
- Inspection, serialization, end-of-line

Each line is “we introduced X / pioneer of Y” — Enovak should use the same *shape* (process + outcome) but only real Enovak work. Never claim their firsts.

**Why-us strip (4 tiles):** Global Manufacturers · Leading Technology · Responsive Service · Industry Support

**CSR block** after the commercial pitch (health, education, remittance, winter drive). Optional for Enovak.

**Do not copy:** 1997 / Rezaul Hasan / 45 engineers / 110 HVAC projects / sister concern Precisa Techno Fabricators / named principal brands (YORK, SIEMENS, CAMFIL, etc.).

## 2. DREKS Associates — landing + a few inner routes

**IA:** Home is still the pitch. Extra routes: `/divisions`, `/projects`, `/pharma`. Footer contact always visible. Heavy “Get A Quote” CTA — Enovak should have one primary CTA, not two stacked.

**Positioning:** industrial equipment for pharma, API, food. ~30 pharmacists + engineers.

**About pattern:** market-gap founding story → HVAC/clean-room milestone → sister unit for turnkey design/execution → one-stop design–install–validate.

**Services on landing (tiles):** Design · Turnkey Solutions · After-Sale Service · Specialist Engineering · Feasibility Studies · Training  
(Their copy on some tiles is leftover web-agency lorem. Ignore.)

**`/pharma` is a product-category index**, not product detail:
Tablet (to OEL5), Capsule, Injectable, PFS, Ointment/Cream, Oral liquid, Eye & Nasal, Inhaler, Suppository, Packaging & Cartoning, PW & WFI, Clean Room Panel & HVAC, Utility.

Enovak `/products` should look like this: category cards → detail pages.

**`/projects` is weak** — generic capability text, no named jobs. Enovak showcase should beat this: year + industry + what was delivered.

**Do not copy:** 1990 / Wahiduzzaman / EDCL + Beximco as first HVAC jobs / TRIPS Associates / their phone/email.

## 3. Saka International — the IA to follow

**IA (use this):**
- Landing: hero → values → mission/plan/vision → services → contributions (achievements) → industries → divisions teaser → contact form + address
- Products live on **separate division/catalog pages** (`machinery_division.html`, `instrument_division.html`)
- Contact is a **section**, not a route

That is Enovak: `/` + `/products` + `/products/{slug}`.

**Values (3 words):** Quality · Knowledge · Responsibility

**Mission / Plan / Vision** as three short lines — steal the *block*, write Enovak’s lines.

**Services (6 tiles):**
- Turnkey pharmaceutical projects (concept → basic/detail engineering → VMP → HVAC/clean room/floor/utilities → install → commission)
- Technological support (pharma + biotech)
- Installation & commissioning of process + packaging machinery (pharma, food, cosmetics)
- Lab instrument install + validation
- Specialized devices / packaging / raw materials
- Turnkey API (and other industrial) projects

**Contributions = achievement list** (same job as Precisa’s process lines and Enovak’s showcase):
- First pulmonary DDS (MDI/DPI)
- Closed-loop / single-pot solid oral
- Coating improvements
- Suppository turnkey
- Alu/Alu + thermoform blister
- Spain-partnered turnkey (design through validation, clean room, HVAC, water, utilities)

**Product catalog pattern (Saka machinery page):** partner/brand cards with a short “what this line is.” Enovak product details: name, category, short description, specs, images, brochure PDF. Do not list their principals (Glatt, Romaco, SKY, OMAG, Analytik Jena, Anton Paar).

**Industries:** Pharma · Food · Cosmetics — Enovak can add general industrial if true.

**Contact block:** address + phones + email + form on the landing. Enovak same.

**Do not copy:** Rangs Panorama / Dhanmondi address, “first to introduce…” claims, their division names verbatim if Enovak’s org isn’t split that way.

## Shared pattern → Enovak rules

| They do | Enovak does |
| --- | --- |
| One long landing | `/` with the same sections |
| Products are the only inner pages | `/products`, `/products/{slug}` |
| Nav = landing sections | Home About Services Products Showcase Contact |
| Showcase = achievements / project history | `showcase_items`, not a logo wall |
| Primary CTA = contact / quote | Hero + end-of-page Contact |
| Tone = formal industrial, first-person company “we”, no startup fluff | Same |
| Brand-name dropping of principals | Skip until Enovak confirms real partnerships |

**Tone samples (rewrite, don’t paste):**
- Precisa: “supply, install, commission, document and validate”
- DREKS: “design, engineering, supply, installation, commissioning and validation”
- Saka: “concept → basic engineering → detailed engineering → VMP → supply → install → commission”

Enovak service copy should use that lifecycle language.

**Visual:** all three are dark/corporate, big hero, card grids, logo or achievement strips, contact form last. Keep Enovak in that family — not a SaaS landing.
