## Contact (Phase 1)

- Form Request validation: name, email, phone, message — all required
- `Mail::to(config('mail.from.address'))->queue(...)` — never `->send()` sync
- Flash success. No DB row
- `.env`: `MAIL_*` + `QUEUE_CONNECTION=database` **or** `sync` only if queue table is forbidden…

**Conflict:** requirements say no DB, and also “queued email.” Laravel `database` queue needs a `jobs` table.

**Phase 1 decision:** `QUEUE_CONNECTION=sync` is cheating. Use **`QUEUE_CONNECTION=database`** only if we run `php artisan make:queue-table` — that is a Laravel jobs table, not Enovak content. Prefer **Redis/SQS later**. For local Phase 1: `database` jobs table is allowed as *infrastructure*, not content. Do **not** create `contact_submissions`.

If you refuse any migration at all: document `sync` as a local exception and switch to queue before deploy. Default in this plan: **one `jobs` migration, nothing else.**

## Tailwind / CSS

Laravel 12 ships Vite + Tailwind. Port prototype tokens into `@theme` / CSS variables:

```
--text #2e1c12
--text-muted #4a3524
--text-on-dark #fbf8f1
--bg #ffffff
--surface #fbf8f1
--accent #2f5a21
```

Fonts: Cinzel (display) + Montserrat (body) via Google Fonts or `@fontsource`.

Do not keep `prototype/styles.css` as a dumped file unless we import it once then delete — prefer Tailwind utilities + a small `app.css` for hero/nav that utilities fight. Match prototype, don’t “redesign.”
